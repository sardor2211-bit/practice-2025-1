# Опрос студентов

## Параметры исследования

| Параметр | Значение |
|-|-|
| Цель | проверить гипотезу о важности стиля преподавателя и определить критерии подбора |
| Респонденты | студенты 1–2 курсов Московского Политеха |
| Количество ответов | 64 |

| Период | апрель 2026 г. |

Вопрос задавался 38 студентам, ответившим «Да» на вопрос 1: 24 из 38 (63%) ответили «да».

## Выводы

1. Гипотеза подтвердилась: стиль преподавателя важен — 47% хотят явно строгого или явно мягкого преподавателя, 63% сталкивались с неподходящим стилем.
2. Главный критерий — умение понятно объяснять (81%), затем рейтинг (66%) и цена (59%).
3. Спрос на сервис есть: 89% ответили «да» или «скорее да».
4. Первые предметы для запуска — высшая математика и программирование.
5. Ориентир по цене — до 1500 ₽ за занятие (75% респондентов).

Эти выводы использованы при выборе весов алгоритма — см. [algorithm.md](algorithm.md).
