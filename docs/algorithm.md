# Алгоритм подбора преподавателя

Код: [src/filin-match.js](../src/filin-match.js). Тот же файл подключён на странице сайта `match.html`.

## Входные данные

Запрос ученика `s`:

| Поле | Описание |
|-|-|
| `subject` | предмет |
| `strictness` | желаемая строгость, 1–5 |
| `budget` | бюджет за занятие, ₽ |
| `format` | `online`, `offline` или `any` |

Профиль преподавателя `t`: предметы, строгость 1–5, рейтинг, число отзывов, цена, формат.

## Формула

Сначала отбираются преподаватели нужного предмета. Для каждого считается итоговая оценка:

```
S = 0,35·Sстиль + 0,30·Sрейтинг + 0,20·Sцена + 0,15·Sформат
```

где

- `Sстиль = 1 − |cпреп − cуч| / 4` — близость уровней строгости;
- `Sрейтинг = R / 5`, где `R` — сглаженный рейтинг;
- `Sцена = 1`, если цена не выше бюджета, иначе `max(0, 1 − (цена − бюджет) / бюджет)`;
- `Sформат = 1`, если формат совпадает или преподаватель работает в обоих форматах, иначе `0,3`.

Сглаженный (байесовский) рейтинг:

```
R = (r·n + 4,0·5) / (n + 5)
```

где `r` — средняя оценка, `n` — число отзывов, 4,0 — априорная оценка, 5 — «вес» априорной оценки в отзывах.

## Обоснование весов

| Критерий алгоритма | Вопрос опроса | Доля |
|-|-|-|
| Стиль (0,35) | «Понятно объясняет» + «Стиль» | 81% и 55% |
| Рейтинг (0,30) | «Отзывы и рейтинг» | 66% |
| Цена (0,20) | «Стоимость занятия» | 59% |
| Формат (0,15) | «Удобное расписание и формат» | 44% |

## Пример

Запрос: высшая математика, строгость 5, бюджет 2000 ₽, формат не важен.

| Преподаватель | Строгость | Совпадение |
|-|-|-|
| Ирина Волкова | 5 | 99% |
| Артём Зайцев | 4 | 90% |
| Алексей Смирнов | 3 | 80% |
