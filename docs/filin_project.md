# Проект «Филин»

## Идея

«Филин» — веб-сервис, который подбирает ученику преподавателя (репетитора) с учётом его стиля обучения. Одним студентам нужен строгий преподаватель, который задаёт высокий темп и жёстко контролирует выполнение заданий, другим — мягкий и терпеливый. Обычные агрегаторы фильтруют только по предмету, цене и рейтингу, поэтому выбор часто оказывается неудачным.

## Проблема

По результатам опроса ([survey.md](survey.md)) 63% студентов, занимавшихся с репетитором, хотя бы раз сталкивались с тем, что стиль преподавателя им не подошёл. 47% ищут преподавателя через знакомых.

## Решение

1. Ученик заполняет короткую анкету: предмет, желаемая строгость (1–5), бюджет, формат.
2. После каждого занятия ученики оценивают преподавателя, в том числе по шкале строгости.
3. Алгоритм считает процент совпадения и показывает трёх лучших преподавателей с объяснением.

## Шкала строгости

| Уровень | Название | Описание |
|-|-|-|
| 1–2 | Мягкий | терпеливо объясняет, не давит сроками |
| 3 | Сбалансированный | ставит цели, проверяет домашние задания, оставляет свободу |
| 4–5 | Строгий | жёсткий контроль, много практики, быстрый темп |

## Целевая аудитория

- студенты, которым нужна помощь с сессией (математика, программирование, физика);
- иностранные студенты, изучающие русский язык;
- преподаватели и репетиторы, которым нужны «свои» ученики.
