# Ход выполнения практики

## 1. Git и репозиторий (5 ч)

- создан репозиторий на основе шаблона [mospol/practice-2025-1](https://github.com/mospol/practice-2025-1);
- освоены команды `git clone`, `git add`, `git commit`, `git push`, `git branch`, `git checkout`;
- изменения фиксировались небольшими коммитами с понятными сообщениями;
- настроена автоматическая публикация сайта через GitHub Actions.

Основные команды, которые использовались:

```bash
git clone git@github.com:sardor2211-bit/practice-2025-1.git
git checkout -b site
git add site/
git commit -m "site: страница с результатами опроса"
git checkout master
git merge site
git push origin master
```

## 2. Документация в Markdown (5 ч)

Все материалы оформлены в Markdown: README репозитория, описание проекта, результаты опроса, описание алгоритма и отчёт о взаимодействии с партнёром. Использованы заголовки, таблицы, списки, блоки кода и ссылки.

## 3. Статический сайт (22 ч)

Сайт сделан на HTML, CSS и JavaScript без генераторов и фреймворков. Страницы:

| Страница | Содержание |
|-|-|
| `index.html` | главная: аннотация проекта, ключевые цифры, роль автора |
| `about.html` | о проекте: цель, задачи, шкала строгости, схема работы, формула подбора |
| `match.html` | интерактивный прототип подбора преподавателя |
| `survey.html` | результаты опроса с диаграммами |
| `members.html` | участник и личный вклад, сертификат |
| `journal.html` | журнал: 6 записей о ходе работы с фотографиями |
| `partner.html` | взаимодействие с организацией-партнёром |
| `resources.html` | полезные ссылки |

Особенности:

- адаптивная вёрстка (CSS Grid, Flexbox, медиазапросы) — сайт корректно выглядит на телефоне;
- диаграммы опроса построены без библиотек: кольцевые — на SVG, столбчатые — на CSS;
- схема работы сервиса нарисована в SVG прямо в разметке;
- демо-подбор использует тот же код алгоритма, что и в папке `src/`.
